About your AI Summary issue
I already found the root cause.
Currently
GenerateSummaryView
does
resume = generate_resume(request.user)
which ignores everything typed into the frontend form.
Your React page sends
{
    name,
    skills,
    education,
    experience,
    projects
}
but Django never uses it.
That's why even after typing manually, the generated result is based on database values (or placeholder data).
We need to make a design decision:
Option 1 (Recommended)
The AI should generate from the user's saved resume.
The form becomes read-only or auto-filled.
This is how LinkedIn, Indeed, and most resume builders work.
Option 2
Generate from whatever the user types in the AI form.
The database is ignored.
This is also valid if you want a free-form AI assistant.
Personally, I recommend Option 1, because your whole project is already built around generate_resume(request.user) as the single source of truth.
