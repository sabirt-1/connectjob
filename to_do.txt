1. the validation checklist 
Why do we validate on the frontend if Django also validates?

Because they serve different purposes.

Frontend Validation (React)
Gives instant feedback.
Avoids unnecessary network requests.
Makes the application feel responsive.
Improves user experience.
Backend Validation (Django)
Protects the database.
Prevents malicious or invalid requests.
Enforces business rules even if someone bypasses the frontend.

A professional application uses both.

So my suggestion is: keep the validation checklist in mind, but let's finish the core functionality first.
 Once the features are complete, we'll polish them all in one focused pass.
